# Examples

The Fig repository contains working samples under [`examples/`](https://github.com/mzbrau/fig/tree/main/examples):

| Project | Purpose |
| ------- | ------- |
| [Fig.Examples.AspNetApi](https://github.com/mzbrau/fig/tree/main/examples/Fig.Examples.AspNetApi) | Canonical ASP.NET Core integration (`AddFig` / `UseFig`), secret providers, custom actions, lookups, status properties |
| [Fig.Examples.AspNetApi.Test](https://github.com/mzbrau/fig/tree/main/examples/Fig.Examples.AspNetApi.Test) | Integration tests for the AspNetApi example |
| [Fig.Examples.ConsoleApp](https://github.com/mzbrau/fig/tree/main/examples/Fig.Examples.ConsoleApp) | Console host using Fig as a configuration provider |
| [Fig.Examples.NetFramework.ConsoleApp](https://github.com/mzbrau/fig/tree/main/examples/Fig.Examples.NetFramework.ConsoleApp) | .NET Framework host via `FigConfigurationManager<T>` |
| [Fig.Examples.DisplayScript](https://github.com/mzbrau/fig/tree/main/examples/Fig.Examples.DisplayScript) | Display-script patterns (modes, validation, information text) |
| [Fig.Examples.Client.Testing](https://github.com/mzbrau/fig/tree/main/examples/Fig.Examples.Client.Testing) | `Fig.Client.Testing` examples for display scripts and settings |
| [Fig.Examples.Yarp](https://github.com/mzbrau/fig/tree/main/examples/Fig.Examples.Yarp) | Managing YARP reverse-proxy configuration through Fig |
| [Fig.Examples.SettingsDataLoader](https://github.com/mzbrau/fig/tree/main/examples/Fig.Examples.SettingsDataLoader) | Registers several sample clients to populate a local Fig instance |

There is also a standalone [fig-quick-start](https://github.com/mzbrau/fig-quick-start) repository with Aspire, Fig API/Web, and a demo app.
